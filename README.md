🛡️ Sentinel

Sentinel is a simple insider threat detection dashboard built with Python and Streamlit. It analyzes synthetic user activity, identifies unusual behavior, and assigns risk scores to help prioritize security reviews.

Features
Risk scoring and categorization
Interactive charts and visualizations
Department and user activity summaries
Filter events by risk level
Upload and download CSV files
Tech Stack
Python
Streamlit
Pandas
Plotly
Run Locally
Clone the repository:
   git clone https://github.com/YOUR_USERNAME/Sentinel.git
   cd Sentinel

Install dependencies:
   pip install -r requirements.txt

Start the app:
   streamlit run app.py

Note

This project uses synthetic data for demonstration. Risk scores are indicators for human review, not proof of malicious activity.
